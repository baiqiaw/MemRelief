# MemRelief 内存管理工具

清理 Windows 残留进程占用的内存：扫描当前进程列表，按安全等级分组推荐可安全结束的进程，一键释放并报告实际释放量。纯手动触发，不常驻、不后台扫描，关闭窗口即零占用。

## 快速开始

- 系统要求：Windows 11 x64。
- 免安装：`MemRelief.App.exe` 为单文件自包含程序，无需安装 .NET 运行时，拷到任意目录双击即可运行。
- 主场景（清理当前用户启动的残留进程）普通权限即可完成。

## 自行构建 exe

前置：.NET 10 SDK。

```bash
dotnet publish src/MemRelief.App -c Release -p:PublishProfile=win-x64
```

产物：`src/MemRelief.App/bin/Release/net10.0-windows/win-x64/publish/MemRelief.App.exe`（干净状态下发布目录内仅此一个文件；发布不清理旧文件，如曾用其他方式发布过，先删除 publish 目录再发布；重新发布前先关闭正在运行的 MemRelief.App）。

## 使用要点

- **列表分级**：✅ 推荐可释放（默认勾选）、⚠️ 谨慎（默认不勾选）、🚫 不推荐（折叠仅显示计数、不可勾选，展开可看原因）。看不懂的项不要勾。
- **加入白名单**：对推荐级/谨慎级条目右键选择"此进程永不推荐"，之后的扫描不再推荐结束它。
- **需要管理员权限的场景**：结束对象属于其他用户、Windows 服务或受保护进程时，这些条目会标注需管理员权限（条目原因中说明），普通权限下一键释放对它们会失败（其余条目不受影响）。需要处理这类条目时，以管理员身份重新运行本工具（右键 exe →"以管理员身份运行"），启动后重新扫描即可操作；勾选状态不落盘，重启后需重新勾选，避免误释放。
- **提权不影响数据**：以管理员身份运行时（UAC 使用当前同一 Windows 账户），白名单与历史记录仍读写同一份数据目录（见下节），不会出现两套数据。

## 数据目录位置

所有自有数据固定落在**当前 Windows 用户**的数据目录：

```
%LOCALAPPDATA%\MemRelief
```

（即 `C:\Users\<你的用户名>\AppData\Local\MemRelief`，资源管理器地址栏粘贴 `%LOCALAPPDATA%\MemRelief` 可直接打开。）

| 文件 | 内容 |
|------|------|
| `whitelist.json` | 白名单（含添加时间、路径、备注） |
| `releases.jsonl` | 释放历史记录（追加写） |
| `releases.1.jsonl` ~ `releases.3.jsonl` | 历史记录轮转副本（单文件到 5MB 滚动，保留最近 3 份） |

- 白名单文件损坏时应用会自动把损坏文件改名保留（`.corrupt` 后缀）并重建空白文件继续工作；历史记录文件损坏时跳过损坏的行继续使用，可解析的记录不丢。两者都不会卡死应用。
- 白名单保存过程中会短暂产生 `whitelist.json.tmp` 中间文件（保存完成即消失），属上表文件的写入形态。
- 除上表及其上述临时形态外，应用不写任何其他数据文件，不改注册表、不改系统配置。
- 首次运行时，程序会把自带的运行组件解压到系统临时目录（`%TEMP%\.net\` 下），这是单文件程序的运行机制，不属于应用数据，可随时删除，不影响功能。

## 已知边界

以下为当前版本已知的行为表现，均为保守方向（宁可不做，不盲目操作）：

1. **计划任务来源可能与实际不符**：某启动项的计划任务只触发一次（不重复），详情仍会按会被周期拉起的方式提示其来源；已被禁用的计划任务也可能仍作为来源展示（来源只说明启动出处，不代表该任务当前启用）。
2. **含 `%变量%` 的自启动项可能显示"无（手动启动）"**：个别注册表 32 位视图里以环境变量形态登记的启动项，无法与进程精确匹配，会显示为无（手动启动）。
3. **来源记录可能重复**：同一启动项在注册表 32/64 位双视图各登记一次时，展开详情可能看到两条重复的来源记录（数据本身忠实，不影响判定）。
4. **签名验证失效时候选全部降入"🚫 不推荐"组**：系统文件签名验证不可用（例如被安全软件清理）时，候选不会盲目放行——全部按不推荐处理（展开原因显示签名验证不可行），"✅ 推荐可释放"组可能为空。这是当前版本的保守行为。
5. **扫描偶发等待**：系统的签名校验服务停滞时，签名验证不会自动超时放弃，个别扫描可能耗时明显变长；候选程序位于网络共享路径（如 `\\服务器\共享\…`）时，读取其文件信息也可能等待较久。

## 便携换机取舍

- **程序随拷随用**：exe 本身免安装，拷贝即迁移。
- **数据不随行**：白名单与释放历史固定落当前 Windows 用户的 AppData 目录，换电脑或换用户登录时不会自动跟随——这是刻意取舍（数据按用户隔离，程序目录保持干净）。
- **需要迁移数据时**：先退出本工具，再把整个 `%LOCALAPPDATA%\MemRelief` 目录拷到新机器同一路径下（注意新机器的用户名可能不同，路径中的用户段要对应替换）。不拷贝则新机器从空白白名单开始，功能不受影响。

## 卸载与数据清除

程序与数据完全分离，卸载分两步：

1. 关闭正在运行的 MemRelief（应用对数据无常驻锁定，但关闭后删除才不会被随后操作"复活"数据）；
2. 删除 exe 与数据目录 `%LOCALAPPDATA%\MemRelief`（白名单与历史记录随之清除，无注册表残留、无系统配置改动）。

首次运行产生的临时解压目录 `%TEMP%\.net\` 如需一并清理可手动删除，不影响任何功能。
