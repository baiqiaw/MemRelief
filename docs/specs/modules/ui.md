# ui 模块规格

## 0. 追溯

覆盖需求：R01–R06 呈现与交互面。上游：[PRD](../../PRD.md)。

## 1. 职责

**管**：WPF 主窗口（概览条/搜索框/三级列表/操作栏/白名单管理面板/确认弹窗/结果报告/右键菜单）、UI 状态机宿主、**组合根与编排**（Core 模块构造注入、扫描链四步编排、日志追加编排）、依据→文案映射、提权重启编排。
**不管**：任何业务判定与执行逻辑（Core）。

## 2. 领域概念

- **MVVM + 组合根**：ViewModel 编排 Core 调用（拉模式，[system §3.1](../system-spec.md)），View 绑定；业务逻辑零下沉。
- **状态机宿主**：[PRD §3.6 五态状态机](../../PRD.md)为本模块唯一状态权威，控件可用性矩阵按其执行。

## 3. 数据模型

无自有持久化实体；绑定模型为 [data-contracts.md](../interfaces/data-contracts.md) 各契约的只读视图投影。

## 4. 行为

### 4.1 关键用例
- **扫描编排**：点"开始扫描" → 转扫描中 → `TakeSnapshot → CandidateIds → CollectSignatures → Classify` 四步 → 渲染三级列表（🚫默认折叠计数、✅默认勾选、组内按 `TreePrivateBytes` 降序、行展开详情、快照时间戳）；`ScanFailed` → 按 [PRD §3.7"扫描失败"行](../../PRD.md)处理。
- **概览刷新三时点**：启动时、每次扫描后、每次释放后（[PRD F5](../../PRD.md)）。
- **释放流程**：点"一键释放" → 确认弹窗（N 树/X MB，取自 `TreePlan`）→ `Execute` + 订阅 `TreeProgress` → `ReleaseCompleted` → 结果报告（双释放量/跳过说明/被拉起预期提示/日志写结果）→ 已结束项移除 + 编排 `IReleaseLogStore.Append` + 提示"可重新扫描"。
- **提权重启**：①列表含预标 `RequiresElevation` 项时，操作栏出现"以管理员身份重启"入口（[PRD F3 触发]）；②结果报告中失败项入口；重启启动参数携带"自动重扫标志 + 上次需管理员失败项清单（名称+可执行路径）"（不落盘，[PRD §3.3](../../PRD.md)）；重扫后**上次失败项高亮**与本次预标并存，用户手动重勾；UAC 拒绝 → 停留普通权限（[PRD §3.7](../../PRD.md)）。
- **右键加白**：列表项右键"此进程永不推荐"——**仅✅/⚠️级项可加，🚫不可加白**（[PRD F4]）；列表尾部折叠区显示"因白名单排除 N 项"计数；白名单管理面板（含元数据、逐项移除）。
- **搜索**：`IRulesEngine.Query` → 任意进程判定结果与依据。
- **关窗语义**：扫描中关窗 = 直接退出丢弃部分结果；释放中关窗 = 取消并**等待 ReleaseCompleted 后方可退出**（[PRD §3.6 注/§3.7](../../PRD.md)）。

### 4.2 状态机

**引用 [PRD §3.6 状态流转表](../../PRD.md)（含确认取消、管理员自动重扫、扫描失败目标态）——不重画。** 技术契约：五态实现为显式枚举 + 单一转换入口。

### 4.3 时序图

跨模块交互见 scanner/releaser 各自 §4.3（ui 为编排者）。

## 5. 接口依赖

- 消费：Core 全部公共契约（`IScanner`/`IRulesEngine`/`IReleaser`/storage 三接口 + 3 个事件）。
- 提供：无（App 为终端层，不被依赖——system 法-1）。

## 6. 约束（模块级）

- **法**：Core 事件 → UI 更新编组到 UI 线程；订阅随窗口生命周期释放。
- **法**：状态机五态外控件状态变更视为违规（可用性矩阵唯一权威 [PRD §3.6](../../PRD.md)）。
- **法**：依据→文案映射表集中在 App 资源；空值口径按 [PRD F2](../../PRD.md)（"(父进程已退出)"/"无（手动启动）"）。
- **情报**：释放进度逐树粒度呈现，不做进程级高频刷新。
