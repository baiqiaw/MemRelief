### 5.5 工作集超标归因（PRD §3.4 预设路径：超标→实测归因→优化或修订指标）

- **发布形态非主因**：Debug 框架依赖空载 269.4MB ≈ Release 单文件自包含 259.7MB（Δ≈10MB，单文件自解压影响有限）。
- **主因：.NET 10 自包含 WPF 运行时基线**——空载私有提交 ~208MB，远高于 PRD 引用的 .NET 8 时代参考值 60-120MB。PRD 附录已预埋：「.NET 8 WPF 基线约 60–120MB……运行时已升 .NET 10，待 net10 空载基线实测后回填」——本次即 net10 基线实测。
- **扫描/渲染增量**：峰值 398.6 − 空载 271.4 ≈ 127MB（600 项构造+1060 行列表渲染，UI 虚拟化下仍有一定增量）。
- **缺陷登记**：issue #45（含本节归因与实测数据）。
- **TL 裁决（2026-09-13）：选项①修订指标，已落地**——PRD v1.4 §3.4 回填 net10 基线口径（空载 ≤300MB / 构造 600 进程扫描后峰值 ≤450MB / 峰值−空载增量 ≤150MB，三项自洽 300+150=450），同步补测量口径与超标治理路径；WBS T-22 AC 与 system-spec §7 同步；裁决落账 decisions-log 2026-09-13 条目。按本矩阵 §7 清零条件，缺陷随 PRD v1.4 合入清零，#45 关闭。
